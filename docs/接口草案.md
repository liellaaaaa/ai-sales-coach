# 接口草案

更新时间：2026-10-05

## 健康检查

- `GET /api/health`：服务状态（含 `voice_configured` 等）

## 认证

- `POST /api/auth/login`：登录，返回 token 和用户信息
- `GET /api/auth/me`：获取当前用户
- `PATCH /api/auth/me`：更新当前用户资料

## 知识库

- `GET /api/knowledge`：登录用户查看知识条目
- `POST /api/knowledge`：管理员新增知识条目
- `POST /api/knowledge/upload`：管理员上传 txt/md 文件并作为知识条目入库
- `POST /api/knowledge/{item_id}/toggle`：管理员启用或停用知识条目
- `GET /api/knowledge/documents`：文档列表
- `POST /api/knowledge/documents`：新建文档
- `POST /api/knowledge/documents/analyze`：解析分析上传内容
- `POST /api/knowledge/documents/{document_id}/versions`：文档新版本
- `PATCH /api/knowledge/documents/{document_id}`：更新文档
- `GET /api/knowledge/documents/{document_id}/chunks`：文档分块
- `POST /api/knowledge/documents/{document_id}/toggle`：启用/停用文档
- `DELETE /api/knowledge/documents/{document_id}`：删除文档

## 训练

- `POST /api/training/sessions`：创建训练，并生成第一句客户回复（多角色 speaker）
- `GET /api/training/sessions`：查看训练历史
- `DELETE /api/training/sessions`：批量删除训练
- `GET /api/training/sessions/{id}`：查看单次训练
- `POST /api/training/sessions/{id}/retry`：基于历史训练创建复训任务
- `POST /api/training/sessions/{id}/messages`：业务员回复，AI 客户继续（支持 `speaker`）
- `POST /api/training/sessions/{id}/stream`：流式客户回复 + 分音色 TTS 音频（SSE）
- `POST /api/training/sessions/{id}/suggestion`：AI 推荐回复
- `POST /api/training/sessions/{id}/live-tip`：旁路实时教练短提示（`after_sales` / `after_customer`）
- `POST /api/training/sessions/{id}/finish`：结束训练并生成七维复盘报告
- `GET /api/training/reports/{session_id}`：查看报告

## 语音

- `POST /api/voice/transcribe`：语音识别（ASR）
- `POST /api/voice/speech`：语音合成（TTS，支持 `speaker` 分音色）

## 设置

- `GET /api/settings/llm`：读取 LLM 配置
- `PATCH /api/settings/llm`：更新 LLM 配置
- `POST /api/settings/llm/test`：测试 LLM 连通性

## 看板

- `GET /api/dashboard/summary`：训练次数、完成次数、平均分、目标分布

## 备注

- 多角色 `speaker`：`buyer`（采购）/ `tech`（技术主管）/ `boss`（厂长）
- 复盘 `scores` 七维：工艺探询、产品选型、技术边界、异议处理、故障归因、价值合规、推进动作
- 鉴权：除 `login` / `health` 外均需 Bearer Token
