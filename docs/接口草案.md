# 接口草案

## 认证

- `POST /api/auth/login`：登录，返回 token 和用户信息
- `GET /api/auth/me`：获取当前用户

## 知识库

- `GET /api/knowledge`：登录用户查看知识条目
- `GET /api/knowledge/documents`：登录用户查看文档列表
- `GET /api/knowledge/documents/{document_id}/chunks`：登录用户查看文档片段
- `POST /api/knowledge`：管理员新增知识条目
- `POST /api/knowledge/upload`：管理员上传 txt/md 文件并作为知识条目入库
- `POST /api/knowledge/{id}/toggle`：管理员启用或停用知识条目

## 训练

- `POST /api/training/sessions`：创建训练，并生成第一句客户回复
- `GET /api/training/sessions`：查看训练历史
- `GET /api/training/sessions/{id}`：查看单次训练
- `POST /api/training/sessions/{id}/retry`：基于历史训练创建复训任务
- `POST /api/training/sessions/{id}/messages`：业务员发送回复，AI 客户继续追问
- `POST /api/training/sessions/{id}/finish`：结束训练并生成复盘报告

## 复盘

- `GET /api/training/reports/{session_id}`：查看报告

## 看板

- `GET /api/dashboard/summary`：训练次数、完成次数、平均分、目标分布
