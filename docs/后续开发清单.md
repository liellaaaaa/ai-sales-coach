# 后续开发清单

更新时间：2026-10-05

## 第一优先级

- 用 5 个以上真实销售场景跑通训练和复盘，校准纺织助剂七维评分权重与硬性扣分规则。
- 产品卡与 `kb/` 同步机制：从代码常量迁出为配置/管理端可维护，覆盖新型号与故障案例。
- 把正式 SOP、话术、产品资料持续导入知识库，验证 grounded 出题引用是否贴切。
- 真机验证准全双工链路：打断、按住说话、live-tip 并行、多角色分音色播放。

## 第二优先级

- 知识库解析覆盖 PDF/Word/网页，并补失败降级与格式提示。
- 文件上传与资料切片体验优化（批量、去重、版本对比）。
- 训练清单状态：待完成 / 已完成 / 需复训；基于上次报告一键再次训练。
- 管理员按账号筛选训练记录；导出复盘报告。
- 语音配置引导页（未配置 MiMo 服务时给出配置步骤，而不只是隐藏入口）。
