## 当前产品决策

### 训练模式要拆成两条向导

不建议让「客户情景陪练」和「商机推进教练」共用同一套向导。

### 客户情景陪练

目标：练客户异议处理和销售话术。

建议步骤：

1. 选择训练情景：价格、交期、品质、回款等。
2. 编辑客户信息：客户名称、产品、需求、客户类型。
3. 设置客户画像：难度、性格、核心关注。
4. 确认训练目标并开始训练。

### 商机推进教练

目标：推进真实商机下一步。

建议步骤：

1. 选择商机阶段：了解商机、确认商机、方案论证、商务谈判、销售成交、回款。
2. 补充推进背景：最近沟通结果、关键阻碍、关键人参与情况。
3. 明确下一步里程碑：关键人会议、测试条件、报价反馈、合同/订单节点、回款时间。
4. 生成推进训练目标并进入对话或推进方案。
