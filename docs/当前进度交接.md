## 当前产品决策

### 训练模式两条向导（已落地）

- **客户情景陪练**：练异议处理与话术。步骤：选情景 → 编辑客户信息 → 设置画像 → 确认目标开始。
- **商机推进教练**：推进真实商机。步骤：选商机阶段 → 补充推进背景 → 明确下一步里程碑 → 生成目标进入对话/方案。

### 行业能力取向

- 对话与复盘必须贴产品卡（型号、参数、工艺边界、故障），不空泛。
- 评分是纺织助剂行业七维，不是通用软技能维度。
- 客户方是多角色（采购压价 / 技术追问 / 厂长拍板），不是单一客户。
