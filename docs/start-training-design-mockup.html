设计意向稿 / Start Training Mockup

把开始训练做成一个训练工作台

目标不是让页面更花，而是让用户一眼知道：先选一个训练情景，再调整客户信息，最后进入下一步。设计重点是减少嵌套边框、降低模板卡文字噪音、让输入区更像可编辑内容。

推荐方向

Direction B：左侧模板列表，右侧编辑客户信息。它比五张横排卡更好扫读，也更像实际工作流。

Direction A Material Cleanup

保留现有结构，只减少灰底和多余边框。成本最低，但视觉提升有限。

Direction B / 推荐 Training Workspace

模板从横排卡片变成可扫读列表，客户信息成为右侧编辑区。

Direction C Guided Setup

做成分步向导，每步只露出一类信息。更清爽，但需要更多交互改造。

客户情景陪练向导

用于练异议处理和销售话术。后端保存为 scenario_coaching flow。

选择训练情景：价格、交期、品质、回款 编辑客户信息：客户、产品、需求、类型 设置客户画像：难度、性格、核心关注 确认训练目标：进入对话并生成客户开场
商机推进教练向导

用于推进真实商机下一步。后端保存为 opportunity_coach flow。

选择商机阶段：了解、确认、论证、谈判、成交、回款 补充推进背景：最近沟通、关键阻碍、关键人 明确下一步里程碑：会议、测试、报价、订单、回款 生成推进训练目标：进入对话或推进方案
